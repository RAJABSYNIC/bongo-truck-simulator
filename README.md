# 🚛 🚌 Truck & Bus Simulator Mobile

Mchezo wa kuendesha Malori na Mabasi (ETS 2 style) ulioundwa maalum kwa ajili ya simu (Mobile Web) kwa kutumia 3D WebGL (Three.js) na React.

## 🚀 Mfumo
- React 18
- Vite
- Three.js
- Mobile Touch Controls (Steering, Gas, Brake, Camera)

## 📦 Kuendesha Kwenye Kompyuta (Local)
```bash
npm install
npm run dev
```

## 🌐 Deploy
Imeundwa kuwa deployed moja kwa moja kwenye [Vercel](https://vercel.com).
